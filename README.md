# UniLab for Linux

Windows 版 **UniLab v1.7 / ScopeView**（USB 数码显微镜软件）的 Linux 重制版。
不是反编译原程序，而是按它的功能用 Python + v4l2 重新实现 —— 因为这类显微镜是标准
UVC 摄像头，Linux 免驱动即可使用。

## 运行

```bash
cd ~/UniLab-Linux
./run.sh           # 或  python3 unilab_linux.py
```

依赖（Fedora 已全部具备）：

```bash
sudo dnf install python3-pyqt6 python3-opencv v4l-utils
```

## 功能

* **实时画面**：自动列出相机，选分辨率（最高 1920×1080 MJPG）
* **图像参数**：亮度/对比度/饱和度/色调/Gamma/增益/锐度/白平衡/曝光/抗闪烁
  （由 v4l2 动态生成，设备支持什么就显示什么）；一键恢复默认
* **视图**：水平/垂直翻转、十字线、网格、放大/缩小/适应窗口、冻结画面
* **采集**：拍照（PNG，带测量烧录）、录像（MP4，开始/暂停/停止）、自定义保存目录
* **测量**：直线 / 水平线 / 垂直线 / 角度 / 圆(圆心+半径) / 三点圆 / 矩形 / 多边形 / 点 / 文字
* **标定（两种）** —— 见下

保存目录默认 `~/UniLab Files`，配置与标定存在 `~/.config/unilab-linux/`。

## 测量前要先标定（用标定片）

显微镜量的是像素，必须先用**标定片**（已知刻度的玻片）告诉软件「多少像素 = 多少微米」。

标定卡上几种图案对应两种标定模式：

| 图案 | 用途 | 模式 |
|---|---|---|
| 直尺(0–40mm)、线段(0.03–0.2mm) | 一维已知长度 | 线性标定 |
| 方格(0.1mm)、直角坐标十字(DIV=0.1mm) | 已知矩形 / XY方向 | 透视标定 |
| 圆形颗粒尺(µm) | 比对量圆颗粒 | 不是标定，是测量参照 |

两个标定对话框都提供**放大镜**（右上角）帮你精确对准细刻度，
并支持 **「每格长度 × 格数」** 输入——画过几格填几格，跨多格可降低误差。

### 1. 线性标定（画面正对镜头时）

1. 把标定片放镜下，调焦清晰
2. 右侧「标定」→ **线性标定…**
3. 沿已知刻度拖一条线（直尺、线段或方格边都行）
4. 填「每格长度 + 单位」和「格数」（如 0.1mm × 10 格）→ 确定

### 2. 透视标定（画面倾斜 / 不正对时）⭐

当镜头与样本平面不垂直（画面有透视畸变）时，像素到实际长度在画面各处不一致，
线性标定会有误差。此时用透视标定（也能处理 X/Y 不等比）：

1. 把一个**已知矩形/方格**参照放镜下（标定片的 0.1mm 方格、直角坐标十字最合适）
2. 右侧「标定」→ **透视标定…**
3. 依次点 4 个角：**左上 → 右上 → 右下 → 左下**
4. 填「每格宽高 + 列数/行数」（如 0.1mm，10 列 × 10 行）→ 确定

软件会算出单应性矩阵（homography），之后**所有测量都会先把像素映射回真实平面再计算**，
自动纠正倾斜透视误差。长度、面积、角度都在纠正后的真实平面上得出。

> 标定会连同标定时的分辨率一起保存；换分辨率时自动换算，一组标定可跨分辨率使用。
> 可保存多组命名标定（如 10x / 40x / 100x），在下拉框切换当前标定。

### ⚠ 关于变焦 / 对焦距离

µm/px 与**放大倍率**绑定。软件无法从 UVC 相机读到当前倍率，**没有跨焦距自动换算**：

* 一旦**变焦**，或这类镜子**改变对焦高度/距离**（等于改了倍率），原标定即失效。
* 正确做法：**每个常用倍率/距离各标定一次并命名保存**，用时在下拉框切到对应那组；
  或在该倍率下重新标定。
* 测量时若未选标定，画布会提示「未标定：显示像素」，结果以 px 显示。

## 测量操作

* 选一个工具 → 在画面上点击/拖拽作图；**右键或 Esc** 取消当前作图
* 多边形：连续左键加点，**双击或回车**结束
* **选择/移动** 工具：点中某个测量可拖动它的端点；选中后按 **Delete** 删除
* 没有标定时测量显示像素(px)；有标定后显示 µm/mm，角度始终是度

## 说明

* 圆/三点圆在透视模式下半径取「圆心→边缘点」映射到真实平面后的距离（近似）；
  需要高精度圆测量时，建议让画面尽量正对后用线性标定。
* 录像为 MP4(mp4v)。若某些播放器不兼容，把保存文件名改成 `.avi` 即可（代码中 `VID_*.mp4`）。
